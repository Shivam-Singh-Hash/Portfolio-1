SkillBridge

An intelligent career & skill-exchange ecosystem — where users barter skills 1-on-1, get AI-driven career roadmaps, schedule peer sessions, and build a reputation. Think LinkedIn + Duolingo + Barter + AI Mentor.

01 · Problem

Why does SkillBridge exist?

Students and early-career developers have skills others need — but no structured way to trade them. A React developer can't afford a Java tutor. A backend engineer struggles with UI. Meanwhile both have exactly what the other needs. The existing platforms either charge money or don't facilitate structured peer learning.

Pain Points

  • No platform for skill bartering — you pay or you don't learn
  • Generic job boards don't help students grow specific skills
  • No AI guidance on what to learn next based on your profile
  • Scheduling peer sessions is fragmented across WhatsApp, Calendly, etc.

Target Users

  • CS students who want to learn without paying for courses
  • Early-career developers filling skill gaps fast
  • Bootcamp graduates with uneven skill sets
  • People who learn better through teaching others
02 · Solution

How SkillBridge solves it

SkillBridge creates a structured marketplace where skills are the currency. You list what you can teach and what you want to learn — the AI matches you with compatible partners, suggests a learning roadmap, and facilitates the entire exchange.

🤖
AI Career Guide
Analyzes your profile and suggests the exact skills that will close your biggest career gaps, with matched learning partners.
🔄
Skill Barter System
Structured 1-on-1 skill exchange — you teach what you know, learn what you need. No money changes hands.
💬
Live Chat & Sessions
Real-time messaging via WebSocket and integrated session scheduling so learning happens consistently.
⭐
Reputation System
Users earn reputation points for quality teaching — creating accountability and a meritocratic skill economy.
📊
Progress Tracking
Track your learning journey — milestones, session history, skill badges earned, and roadmap completion.
🔐
Secure Auth (JWT)
Spring Security with JWT tokens for stateless, secure authentication across the full platform.
03 · Architecture

How it's built

A clean separation of concerns — React frontend communicates with a Spring Boot REST API, while WebSocket handles real-time messaging. MySQL stores relational data with optimized queries for the matching algorithm.

04 · Challenges & Learnings

What I learned

01
Designing the matching algorithm — Building a skill compatibility score that weighs teaching strength, learning goals, and availability required careful normalization of heterogeneous user data. I learned how to preprocess and vectorize profile data using Python before feeding it to the scoring model.
02
WebSocket at scale — Implementing real-time chat with STOMP over WebSocket in Spring Boot required understanding connection lifecycle, heartbeat management, and graceful disconnection handling. Stateless JWT authentication with WebSocket was a particularly interesting challenge.
03
Database schema design — Modeling the many-to-many barter relationship between users, with sessions, reputation, and skill listings all interconnected, taught me to think deeply about normalization vs. query performance tradeoffs in MySQL.
04
React state management — Managing complex async state across the matching dashboard, chat system, and session scheduler without Redux required creative use of Context API and custom hooks to avoid prop drilling and unnecessary re-renders.
